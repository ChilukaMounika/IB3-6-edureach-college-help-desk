# EduReach College Help Desk Chatbot

## Project Overview
EduReach is an AI-powered College Help Desk application that helps students get information about their college.

## Purpose
The chatbot answers student queries quickly without requiring manual support.

## Main Features

- Answer college-related questions
- Retrieve information using AI
- Display chatbot responses
- Easy-to-use web interface
- Fast response time

## Functional Requirements

- User can enter a question.
- Chatbot processes the question.
- Chatbot searches the knowledge base.
- Chatbot returns the most relevant answer.
- User can continue asking questions.

## Non-Functional Requirements

- Fast response time
- User-friendly interface
- Reliable answers
- Responsive frontend

## Frontend Pages

- Home Page
- Chat Interface

## Expected Behaviour

- Input field should accept user questions.
- Send button should submit the query.
- Chat history should display correctly.
- Errors should be handled gracefully.
- Loading indicator should appear while waiting for responses.
